# VibePulse 🎵 — CodSoft Web Development Internship, Task 3

This repository contains **Task 3** of my **CodSoft Web Development Virtual Internship**:
**VibePulse**, a custom music player built with HTML, CSS, and JavaScript.

## 📋 Task Overview

Build a music player web application with the following features:
- Play, pause, and skip tracks (next/previous)
- A progress bar showing playback position, with click-to-seek
- A playlist/song list the user can browse and select from
- Repeat and shuffle playback modes

## ✨ Features

- Play / pause toggle with animated icon
- Next / previous track controls
- Click-anywhere-to-seek progress bar with live current time / duration
- Repeat playlist, repeat one song, and shuffle modes
- Expandable song list panel showing all tracks and their durations
- Fully responsive, card-style player UI

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)
- Material Icons (Google Fonts CDN)

## 📁 Project Structure

```
.
├── index.html
├── style.css
├── script.js
├── music_list.js     # song data (name, artist, image, audio file)
├── images/             # album art (.jpg)
└── songs/               # audio files (.mp3)
```

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/arth-codes/CODSOFT_TASK-3.git
   ```
2. Add your own album art to `images/` and audio files to `songs/`.
3. Update the `allMusic` array in `music_list.js` with your song names,
   artists, and file names.
4. Open `index.html` in a browser.
